# 本地工参、首页日志与路测记录管理

## 本地工参

在“导入工参”页面点击“本地工参管理”，可搜索、分批预览、新增、编辑和删除 LTE / NR 工参。服务基站详情弹窗也提供“编辑本地”和“删除本地”；只有云端查询结果时，可先“保存为本地副本”。

普通用户的服务基站名称为“未知”时，该文字显示为蓝色，点击即可随行随录并保存到本地。已有云端录入权限的用户仍使用原有认证流程提交云端，也可以单独选择保存到本地。

本地用户工参存入独立的 `managed_cells` 表，查询优先使用这些记录；云端查询缓存刷新及缓存清理不会覆盖或删除它们。本地管理动作不调用云端增删改接口。

工参数据库 1 → 2 自动迁移可识别的旧版导入数据。旧版来源不明确的记录及查询缓存保留在“历史本机副本”，可以管理本机副本；编辑保存后归入“我的工参”。名称、坐标、方位角、频点等均可修改，RAT 与小区长号作为记录标识保持固定。坐标使用 WGS84。

## 首页日志

首页录制面板新增“日志管理 · 导入 / 导出”。停止录制后，每次日志独立归档，管理页支持采样预览、回读、删除及 CSV 导出，也可导入 CSV 和旧版 JSON 日志。旧版仅保存的最后一次 JSON 录制会迁移到管理列表。

CSV 使用 UTF-8 BOM，Excel 可以直接打开；字段包含时间戳、双卡信号与小区信息、QoS 和全局事件。`sample_json` 保留完整快照，重新导入时优先使用该列；若需要通过表格修改可见字段后导入，应删除对应的 `sample_json` 列。旧版应用导出的平面 CSV 也支持导入。

## 路测记录

路测地图的“路测记录”打开独立管理页面，沿用首页主题与卡片样式，支持城市/开始时间搜索、回读、继续录制、打点预览、删除和 CSV 导入导出。导入会创建新的 Session，避免覆盖已有记录，同时保留双卡数据、分段及服务站快照。

主要坐标字段如下：

| CSV 列 | 含义 |
| --- | --- |
| `raw_latitude` / `raw_longitude` | 定位回调取得的原始纬度/经度 |
| `raw_coord_type` | 原始坐标类型，如 WGS84、GCJ02；惯性估算使用 WGS84_ESTIMATED |
| `wgs84_latitude` / `wgs84_longitude` | WGS84 纬度/经度，原始为 WGS84 时直接保留，否则从 GCJ02 换算 |
| `wgs84_origin` | WGS84 来源：raw、converted_from_gcj02 或 legacy_converted_from_gcj02 |
| `gcj02_latitude` / `gcj02_longitude` | 地图使用的 GCJ02 纬度/经度 |

路测数据库 5 → 6 保留已有记录，并新增可空的原始坐标字段。旧记录未保存的原始坐标保持为空，导出的 WGS84 换算值明确标记为历史换算来源。

其他列包括毫秒时间戳 `timestamp`、卡槽 `sim_slot`（1 或 2）、信号、小区、估算标记、精度、分段标记、`snapshot_json` 和 `station_snapshot_json`。外部 CSV 至少提供 `timestamp`、`sim_slot` 及成对的 GCJ02 或 WGS84 坐标；仅有 WGS84 时自动换算地图坐标并保留输入为 WGS84_IMPORTED。完整 CSV 的快照列优先用于恢复原始信号和服务站信息。

导入读取 UTF-8 文件，先校验内容再写入；单次文件上限为 64 MB。导出使用系统文件选择器保存，首页日志与路测点均采用 CSV 格式。
