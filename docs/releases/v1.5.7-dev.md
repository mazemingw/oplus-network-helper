# v1.5.7-dev · 路测地图与新机兼容更新

版本：`1.5.7-dev` / versionCode `57`，Android 10 及以上，`arm64-v8a`。此版本按现有版本号发布为预发布版。

## 更新内容

- 修复部分新机 NRCA 带宽显示翻倍的问题，按系统能力选择带宽枚举，保留旧系统解析规则。
- 接入高德 Android 猎鹰驾车轨迹纠偏。采集随开始/停止路测打点运行，修复仅停留地图也采集和绘制青线的问题。
- 新增独立的 4G/5G 频段筛选，支持逗号分隔，实时打点和历史回读使用相同条件。显示具体频段、覆盖长度、总有效距离及比例；未命中区段保留灰色路测路径，完整原始数据继续保存。
- 调整半透明地图浮层：右上地图/视角/速度，右下定位/录制/更多 FAB 与 RSRP 图例对齐，底部中央提供缩放控件。
- 服务基站使用绿色标记；点击基站或路测点显示箭头气泡与选中光圈，点按气泡可复制全部信息。
- 补齐首页小区查询接口兜底、整站独立 anchor 解析和精确小区缺频点兼容；缺少有效坐标时显示明确状态。
- 路测点及 CSV 增加 RSRQ、SINR、NR SS 指标，保存双卡记录、原始坐标及连接基站快照，支持离线回读和续录。
- 完善本地工参、随行随录、首页日志与路测记录管理，以及 CSV 导入导出。
