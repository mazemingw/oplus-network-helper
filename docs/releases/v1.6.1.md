# v1.6.1

版本：`1.6.1` / versionCode `61`，Android 10 及以上，`arm64-v8a`。

## 更新内容

- 接入 bunnylock 的自动后端识别及高通 QMI、联发科 AT、Pixel、Android HAL 后端，支持设备提供的 Root / Shizuku 连接方式。频段、小区控制继续共用欧加助手的界面，按后端能力显示选项。
- 新增“驱动&设置”：后端切换、移动网络/基带重启、清理通道、AT 控制台、设备及日志信息，展示上游图标与项目致谢。
- 清理通道后等待重连与实际读取验证。普通清理仍失败时列出已知系统 NAS 使用组件、状态、作用与影响；用户确认后逐项暂停、重试，也可手动恢复。原有 QMI 驱动验证控制与监测两路客户端同时可用。
- “替我决定”默认开启，仅预选无线扩展组件并等待用户确认；“自动恢复”默认关闭，启用后退出应用恢复助手暂停前正在运行的组件，保留原先已停止的状态。
- NRCA 按当前 SIM / 小区统一裁决：工程模式优先，短暂坏帧保留仍有效的工程模式报告，过期后回退 QMI。QMI 聚合显示补入主载波；控制页高亮已配置的辅载波频段，驻留成功判断仍只采用真实活动载波证据。
- 实时邻区固定保留五行，缺少数据时留空，多余项可展开。改进小区候选、NR 多 PCI 输入、控制页滑动 Tab、悬浮状态提示及布局。
- 首页多天线 RX 使用稳定行数与更紧凑的彩色测量、平滑 PHASE 饼图；改进首页切卡布局、底栏宽度和应用显示密度设置，默认使用 ECharts 图表。
- 修复路测 GPS 中断时的位置选择和持续双卡采样链路，支持就绪的 IMU 估算坐标并标记 INERTIAL；位置不可用时仍保存无线数据，不重复伪造旧 GPS 坐标。改进行驶/静止方向、基站距离连线及历史回读。

## 验证与说明

本轮按要求仅进行 Debug 编译验证，构建通过；发布 APK 的内嵌版本、ARM64 架构和 v2 签名验证通过，签名证书与历史版本一致。没有在本轮执行真机系统服务停启、锁定或覆盖安装，也没有把历史测试数量作为本轮结果。

系统组件列表依据已提供的 PLK110 诊断材料，并结合本机 init 定义和进程身份核对；运行状态不是实时 NAS 占用计数，容量与作用不能直接推广到其它固件。自动恢复包含正常退出和 Root guardian 进程死亡兜底；如果系统同时终止 guardian，即时恢复无法保证，下次启动会处理遗留归属记录。详情见 `docs/qmi-system-recovery.md`。

各后端能力取决于设备、权限、基带和厂商接口；MTK、Pixel、HAL、双卡写入、惯导及恢复流程仍需相应设备验收。
