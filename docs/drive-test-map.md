# 路测地图：双卡记录与附近基站

适用于源码 v1.5.7-dev / versionCode 57。

## 绘制与探测设置

路测地图 FAB 中原“扇区绘制参数”已扩展为“地图绘制与探测参数”，在可滚动对话框中同时设置：

- 扇区角度、绘制距离和路测采样间隔。
- 基站切换点显示、当前服务基站扇区、红色连接线及距离标注的独立开关。
- 自动隧道惯性估算开关，默认开启，进入地图后随 GPS 行驶观测自动校准，无需停车。
- 附近基站自动探测开关，默认关闭。
- 探测半径 1–10 km，默认 3 km。
- 制式：全部、4G (LTE)、5G (NR)。
- 可选 Band：留空、数字、`B` 或 `n` 前缀；支持逗号分隔多项，例如 `B1,B3,n78`（最多 32 项）。客户端分批调用原有单频段接口并合并、去重，不需要更新后端。

保存后设置在下次进入时保留；“立即探测”可发起一次查询。开启自动探测后，定位回调按时间和移动距离节流查询，地图暂停时不发起自动查询。圆圈显示查询半径，状态文字显示结果或失败原因。

卫星/标准地图、2D/3D 和速度块置于右上方双卡面板下方；定位、录制和更多三个 FAB 置于右下方，与左下角 RSRP 图例底部对齐。所有按钮统一 48dp 宽，横屏或短窗口自动变为右上和右下两排，极小窗口可在组内滚动，避免两组叠在一起。高德原生缩放按钮关闭，底部中央提供减号与加号。浮层使用半透明背景并适配深浅主题。顶部双卡 TAB 精简为运营商、制式和信号；纠偏状态与服务站共用一行，详情点击查看。左下角图例与原始轨迹、打点使用同一套 RSRP 阈值。

点击基站或路测点时显示带指向箭头的气泡，选中标记放大并加蓝色光圈，仍保留服务站绿色或原始信号颜色。气泡使用可交互视图，底部“复制”按钮将标题和完整详情写入系统剪贴板并显示 Toast；点击地图空白处清除气泡和高亮，切换选择恢复旧标记；缩放抽稀保留正在查看的打点。

点击探测基站、当前服务站或 session 回显的历史基站，都会同时显示名称气泡、展开工参中已有方向角的天线面（室分/微站使用圆形覆盖示意）；历史基站不要求位于当前探测范围内。气泡可“钉住天线面”。钉住后，点击其他基站、地图空白或重新探测均保留该天线面，直到取消钉住或地图组件销毁；未钉住的天线面随选择切换。工参缺少方向时不猜测方向角。

未开始录制且未回读历史时，点击基站会增加从当前有效定位出发的蓝色虚线，标注“查看距离”及点站直线距离；位置变化时更新，较远时在用户附近补充距离标签。该线仅用于查看，不改变绿色服务站匹配及记录内容。切换基站、点击路测点/地图空白、开始录制、回读或退出地图时更新或清除；钉住仅保留天线面，不保留多条查看连线。没有有效定位时明确提示等待。

“更多”FAB →“去除基站”支持多选 B1、B3、B5、B8、B34、B38、B39、B40、B41，以及逗号分隔的 LTE EARFCN。命中任一条件即隐藏对应 LTE 基站、天线面和服务站连线，探测结果也受该规则约束；NR 与原始打点记录保持完整。规则在本机保存，状态栏列出已屏蔽条件，“全部恢复”清除规则。

打点保留 RSRQ、SINR 及 NR 的 SS-RSRP、SS-RSRQ、SS-SINR；弹窗按实际字段显示 SS 标签，不将通用值冒充 SS。CSV 新增对应独立列，兼容缺少这些列的旧文件。系统未提供的指标保持空值。

## 打点频段筛选与覆盖率

入口统一收在右侧“更多”FAB →“频段筛选与覆盖率”。分别填写 4G 与 5G 的频段列表，再点击“应用筛选”。支持英文/中文逗号、逗号两侧空格、重复项及对应的 `B` / `n` 前缀，例如 4G 输入 `3,41`、5G 输入 `41,28`。格式错误会在对应输入框提示，原筛选保持不变。开启筛选时，FAB 菜单中对应项目显示勾选标记。

- 只填写 4G：仅显示指定 LTE 频段；只填写 5G：仅显示指定 NR 频段。两边都填写时取两组结果的并集，4G B41 与 5G n41 独立匹配。
- 两框留空后应用，或点击“清除筛选”，恢复全部打点。筛选会记住，并应用于两张 SIM、实时打点、历史回读、CSV 导入后的回读及续录显示。
- 按每个打点的服务制式与记录的 Band 精确匹配；不按 CA 组合文本或频点号猜测 Band。筛选时缺少 Band 的旧点不会被视为命中，清除后仍可查看。
- 原始采样、完整记录和 CSV 导出保留全部数据。匹配频段保留彩色线和打点，被筛掉的路测段以带深色描边的亮紫色背景线显示路径，不显示这些频段的打点，也不计入频段覆盖长度；没有频段标识的云端青色轨迹在筛选期间隐藏。紫色线和彩色线使用相同的有效定位与分段规则，定位空档、异常跳点及续录断档不会被补连。
- 历史面板使用匹配打点的快照，视角移到所选 SIM 的首个匹配点，相关历史服务站同步筛选；无匹配时显示空结果，不回退显示其他频段。附近基站探测有自己的制式/Band 条件，不受本打点筛选修改。

同一对话框可开关“在地图显示覆盖率”。开启筛选后，半透明卡片显示所选 SIM 的覆盖百分比、当前筛选的具体频段、匹配频段的连线距离与总有效路测距离。4G 与 5G 分行显示，例如 `4G B3,B41`、`5G n28,n41`；较长的列表自动换行，避免省略后无法确认完整条件。实时打点、切换 SIM、回读和更改筛选均自动重算。竖屏卡片位于顶部面板下方，横屏位于底部缩放控件上方，操作和设置统一由 FAB 进入。筛选与浮层开关均会记住。

计算口径：**覆盖率 = 两端均匹配的有效相邻打点距离之和 / 当前 SIM 全部有效相邻打点距离之和**。多频段取并集，不重复计长；分母使用完整原始点集，不随显示筛选缩短。未匹配频段的紫色路径只作路测参考，不计入覆盖长度；续录分段、超过 120 秒的定位空档、无效坐标或超过 100 m/s 的异常跳点不跨接。小于 2 米的移动不计入距离，保持与路测里程的抖动剔除一致。例如原始有效路线 1 km，其中命中频段的连续线段总长 400 m，显示 40%。没有有效距离时显示“—”。频段切换边界两端不同时命中的区间不补造覆盖长度，因此这是相邻打点的保守估算。

2026-10-23 验证：77 项地图相关单元测试通过，Debug 与 R8 Release 构建通过。AVD 的模拟行驶记录验证了实时筛选后 `21 m / 21 m = 100%`、无匹配频段时 `0 m / 21 m = 0%`；41 点记录回读后无匹配显示 `0/41`，清除筛选恢复全部 41 点。统计卡片的横竖屏布局和 FAB 统一入口已检查。数据为模拟器注入的定位，未作为真实道路或射频覆盖验收；当前 AVD 的底图 ARM 原生库限制仍见猎鹰接入说明。

后续修复：猎鹰采集与开始/停止打点绑定，右侧操作分为上方状态组与下方 FAB 组；增加服务站绿色标记、选中光圈和可复制的信息气泡。新增查询回归覆盖整站接口失败时使用首页小区接口兜底、独立 anchor、工参频点缺失、坐标缺失/非法以及取消查询；地图相关测试共 87 项通过，Debug 与 R8 Release 构建通过。按用户要求未继续横屏测试；本轮地图标记点击和完整云端轨迹仍未完成真机验收。

打点按轨迹顺序约每 4dp 保留一个显示点，各缩放级别使用相同的 4000 个标记上限，不再缩小到只有 100/220 个点。另按全部原始采样绘制带信号颜色的连续轨迹，保留弯道、经过视野外的路径和往返路线；续录分段、超过 120 秒的定位空档及明显跳点之间不连线。放大或移动地图时重新选点，显示抽样不会删除采样数据；关闭切换点标记也不会切断轨迹或影响录制。点击基站标记后，弹窗名称可自动换行。

## 当前服务基站

按当前选中 SIM 的 RAT 与 ECI/NCI 核对工参记录；无小区长号时需要 TAC、频点、PCI 同时匹配且站址唯一。未匹配的附近站不会被标为服务站，切卡、切制式或切小区后会清除旧结果并取消旧请求。

查询先使用与首页相同的本地工参，再查询整站接口；整站接口不可用、不含精确匹配小区或缺坐标时，以首页的小区查询接口兜底。整站响应的独立 `anchor` 字段也参与匹配。ECI/NCI 精确命中时，工参频点缺失或重耕后与手机频点不同不再导致拒绝；同 ID 的多条记录依次优先使用 TAC、PCI、频点一致的记录，剩余坐标仍不唯一时不猜测站址。没有小区 ID 时仍要求 TAC、频点、PCI 全部一致，不采用附近或模糊小区代替服务站。已匹配但缺少有效坐标时明确提示“已匹配服务小区，但工参缺少有效坐标”，不伪造站址。

服务站匹配另有 50 km 的距离保护，与附近探测的 1–10 km 半径独立。这是抑制错误工参的保守产品阈值，不是无线覆盖极限：将地图 GCJ-02 定位转换为 WGS84，先排除超限候选，再进行标识及 TAC/PCI/频点核对；不会因最近而选择标识不符的站，也不按省界屏蔽边界附近的合法站址。本地缓存中的远站不能阻止继续查询整站及小区接口。尚未取得有效定位时显示等待，定位到达后自动匹配；旧定位超过 5 秒或非惯导定位精度差于 100 m 时不用于匹配。异步查询返回时及后续位置变化时再次校验，超限服务站不绘制标记、天线面及连线，不保存成已匹配站。原始无线采样保留。历史回读按每条服务站快照当时的记录位置过滤异常站址，点击打点后也按该打点位置复核；不修改或删除原有记录。

匹配后在顶部提示条显示站名，以绿色标识当前服务基站并置于附近红色标记上层，自动展开当前服务站的扇区；附近探测结果默认仅显示基站标记，点击后可展开、钉住。切换服务基站或 SIM 时清除旧服务站扇区，探测基站的钉住状态独立管理。可独立关闭当前服务站扇区或红线/距离。连线为当前位置与服务站之间的直线，距离不是道路距离。回读时使用所选 SIM 的历史起点和历史小区，当前打点所连服务站显示绿色，不混入实时服务站。工参缺少方向或坐标时无法补造天线方向或站址。

录制期间实际显示连线后，按 Session、SIM 和服务小区保存站址、已取得的天线面、方向角、频点及首次连线的位置。回读时保留历史基站标记，仅展开当前打点对应服务站的扇区及连线；默认选所选 SIM 的首个打点，点击其他打点后切换对应服务站。没有匹配快照时不随意展开其他站的扇区。快照回读无需重新联网查询，切换 SIM 也会切换对应基站组。删除或清空记录会一并删除这些快照，退出页面不取消已经排队的保存。点击打点后，气泡及顶部状态显示该点对应的历史站名和点站直线距离，绿色标记及天线面随选择切换；连线从点击的打点出发，不使用当前手机位置或快照首次保存的位置。按保存的小区 key、SIM、制式核对，缺少 key 的旧打点可按自身快照重建 key。没有可用服务站快照的旧记录会明确提示并清除旧连线，不用当前工参补造历史连接。

点击基站或打点后的信息窗保留原频点号，并追加 MHz 频率。LTE FDD 显示下行与上行，TDD 显示共用频率，NR 按全局频点栅格换算；未知制式或不支持的频点不猜测频率。

| 制式 | Band | 显示范围 |
| --- | --- | --- |
| 全部 | 留空 | 所有 4G / 5G 频段 |
| 4G | 留空 | 所有 4G 频段 |
| 5G | 留空 | 所有 5G 频段 |
| 4G | 3 或 B3 | 4G B3 |
| 5G | 78 或 n78 | 5G n78 |
| 全部 | 3 | 4G B3 + 5G n3 |
| 全部 | B3 | 4G B3 |
| 全部 | n78 | 5G n78 |

制式与 Band 前缀冲突时不提交设置。后台不支持的 Band 会显示提示。更改筛选会清除旧结果并按新条件查询。

这些结果来自工参库，覆盖取决于库中已有坐标。客户端将地图 GCJ-02 坐标转换为 WGS84 查询，返回结果转换到地图坐标绘制。后台先筛选制式、频点与圆形距离，再按距离排序，每种制式最多返回 1000 个小区；达到上限时提示缩小范围。地图按站址合并展示，因此站数与小区记录数可能不同。

Band 按 EARFCN / NR-ARFCN 范围判断。NR 频段范围存在重叠，例如 n77/n78；筛选结果不能单独证明基站实际配置的 Band。

## 双卡录制与回读

每次采样使用同一定位与时间戳收集两张卡的可用快照，并以一个批次写入 Room。当前选择的 SIM TAB 只决定地图和面板显示哪组数据，两张卡都会记录。停止时等待待写入批次完成并自动保存，不再弹出保存/不保存对话框。返回退出、页面销毁时也保留记录，已排队的数据库写入不随页面取消。系统强制结束进程时，以此前已提交的打点为准。

“路测记录”在独立管理页中按起点城市和开始时间列出，并显示估算长度。页面沿用首页主题和卡片样式，支持搜索、打点预览、回读、续录、删除及 CSV 导入导出。城市从起点地址获取，地址不可用时显示“起点城市未知”；内部 Session ID 仍保持稳定。双卡相同定位只计算一次距离，滤除极小抖动和明显跳点，长度是打点之间的距离估算。

点击记录卡片的“继续录制”，会在同一个 Session 中追加双卡打点。每次续录建立新的分段，不将退出期间的空档或移动距离算入里程。原有记录和起点城市保留。“回读”只显示历史，不会开录。显式删除或清空当前 Session 才会移除记录。

本地路测数据库从版本 3 迁移到 4，新增 Session 元信息、定位估算标识、精度、分段标记及按 Session/时间的索引；保留旧记录。旧 Session 首次读取列表时补算长度，缺少历史地址的记录仍显示未知城市。

数据库版本 4 → 5 新增 `drive_stations`，保存每条记录的服务站与天线面快照，保留原有打点和 Session 元信息。

数据库版本 5 → 6 新增原始坐标及坐标类型，保留旧打点。CSV 提供原始坐标、WGS84 与 GCJ02 坐标及来源标记，并携带双卡信号与服务站快照；旧记录没有原始坐标时保持为空。导入创建新的 Session，避免覆盖本机记录。字段与入口说明见 [本地数据管理](local-data-management.md)。

进入地图时显示实时数据和当前位置，不自动读取历史 Session。通过“路测记录”管理页主动“回读”记录后：

1. 读取整段记录并按 SIM 分组。
2. 将视角移到整段记录最早的有效打点位置。
3. 用 SIM TAB 切换面板和轨迹数据组；历史显示不混入后续实时信号更新。

旧单卡记录仍可读取，未记录的另一张卡不会生成历史数据。无法取得快照的 SIM 也不会补造记录。开始新的路测切换回实时采样；定位与电话权限需要按提示授予。

## 速度与隧道惯性估算

右侧面板仅显示速度（km/h）与惯导“就绪／未就绪”，没有可用速度时显示“—”，不显示 GPS 失锁、定位来源、校准过程或漂移数值。高德 SDK 的有效定位回调始终优先更新地图及采样位置，不受惯导校准状态或惯导精度门槛阻挡；SDK 缺少单调时钟时间戳时使用定位 UTC 时间，均未提供时按成功回调接收时间处理。惯导没有独立的 GPS 订阅，只从 SDK 接收 GPS 观测；仅 SDK 定位中断超过 3 秒且惯导就绪时补偿位置。传感器启动或融合失败不会影响 SDK 定位。普通定位精度大于 100 m 时不用于路测采样，此条件与惯导就绪状态无关。

1. 打开地图即启动 GPS、加速度计和陀螺仪融合，默认启用惯性估算；设置中可以关闭。
2. 手机固定后正常行驶即可。GPS 速度达到 2 m/s 且有可靠航向时自动定向，通过多次 GPS 观测学习传感器偏差。无需停车或手动操作；原停车校准按钮已移除。
3. GPS 速度变化及航向变化分别校正加速度偏差、陀螺仪偏差，转弯和加减速不会直接被当成静止偏置。定位中断期间持续积分陀螺仪航向并投影加速度，能够估算弯道和速度变化；不会在每个传感器事件中反复套用旧 GPS 航向。
4. SDK 定位中断超过 3 秒后才使用可用的惯性估算；GPS 恢复后按测量时间重新锚定，再补算该时间之后的传感器数据，避免延迟回调重复积分。惯导未就绪时继续正常定位与打点。

优先使用不依赖磁场的游戏旋转向量进行姿态变换，首次用绝对旋转向量及磁偏角建立地理东/北参考；失锁后航向由陀螺仪更新。原始加速度计作为无重力加速度传感器的后备，在地理坐标中去除水平重力分量。缺少陀螺仪、加速度或姿态传感器，传感器不可靠或采样中断时停止惯性估算；恢复后利用 GPS 自动重新校准。失锁后的最长推算时间默认 10 分钟，可设置 1–30 分钟；漂移指示持续增长，达到时限或传感器中断才停止。速度面板显示就绪或推算状态；估算来源和漂移指示保留在打点数据及回读弹窗中，漂移指示并非实测置信半径。

手机移动、隧道内磁干扰和加速度偏置都会累积误差，惯性估算尚需实车验证，不能保证长隧道轨迹准确。传感器坐标和校准依据 [Android 运动传感器说明](https://developer.android.com/develop/sensors-and-location/sensors/sensors_motion)及 [AOSP 传感器类型说明](https://source.android.com/docs/core/interaction/sensors/sensor-types)。

## 后台接入

可选的“猎鹰轨迹纠偏”默认关闭，开启后向高德上报驾车轨迹并显示云端绑路结果，无须导入线路文件。保留积分引擎、原始打点与双卡信号，当前不提供铁路或地铁纠偏。配置、运行规则和验收步骤见 [猎鹰轨迹纠偏接入](map-matching-mvp.md)。

后台：[NetworkHelperBack](https://github.com/mazemingw/NetworkHelperBack)，Apache 2.0。

接口为 `POST /networkhelp/cell-params/nearby`，携带 WGS84 的 `latitude`、`longitude`、`radius_km`，以及可省略的 `rat`、`band`。完整协议与错误码见 [接口说明](https://github.com/mazemingw/NetworkHelperBack/blob/main/nearby-api.md)，环境配置和部署见后台 README。

已有工参数据库不需要为附近查询功能改表。服务端需包含 `nearby.js`、`nearby-bands.js`，并由 `routes.js` 注册路由；更新后重启服务。Git 推送不会自动重启线上服务。

2026-10-22 的地图交互、Session 与惯性估算修改均在 Android 客户端完成，不需要新增后台接口。

## 验证与手工测试

本次修正通过 Android 单元测试与 Debug 构建，并使用 AVD 检查地图浮层及 SDK 生命周期。模拟用例覆盖行驶中自动校准、左右隧道弯道、加减速、GPS 延迟与恢复、传感器中断、倾斜/横竖安装坐标变换、缩小打点密度、轨迹分段、云端结果时效以及信号字段和 CSV 往返。尚未进行 OPPO 实车调试。

后续回归覆盖 SDK 无单调时间戳的定位、GPS 显示与惯导校准解耦、离线站点/扇区快照与 SIM 隔离、频率换算和地铁/高铁专网标签；SQLite 迁移检查验证 4 → 5 保留旧记录、双卡键互不冲突及关联快照删除。

建议手工检查：

1. 已有多个 Session 时进入地图，确认仍位于当前位置。
2. 双卡录制时保持一个 TAB，停止保存后恢复，确认另一个 TAB 也有记录。
3. 回读位于远处的 Session，默认应完整展示当前卡的可见轨迹；将“回读初始视角”改为起点后重新回读，确认镜头转到最早打点。再切换双卡、过滤频段并读取旧单卡记录。
4. 分别查询全部制式、仅 4G、仅 5G，并测试留空 Band、数字和前缀 Band。
5. 将半径设为 1 km 和 10 km，检查范围圆圈及结果刷新；尝试冲突前缀与不支持的 Band，检查提示。
6. 缩小地图，确认点仍密集且完整轨迹连贯；往返、转弯和视野边缘不能断线。关闭切换点时轨迹仍连续，续录空档及明显跳点则不能被连线。
7. 录制后直接返回或划走应用，再进入记录列表检查自动保存；选择该记录并继续录制，确认旧数据保留且空档不计入长度。
8. 开启附近探测，确认附近站仅显示标记，仅当前服务站显示扇区；换卡、换制式或换服务站后检查旧站扇区消失。回读时点击不同打点，确认始终只展开对应服务站。
9. 行驶中打开地图，确认无需停车或点击按钮即可自动校准；测试短时失锁中的左右弯道、加减速和重新捕获，并核对估算标记与 设置时限的失效行为。分别测试横屏、竖屏和倾斜固定手机。
10. 首次打开地图时分别检查网络定位和 GPS 定位；录制时经过多个服务站，退出后离线回读，检查两张 SIM 的基站、扇区、连线及弹窗 MHz 频率。
11. 双卡信号对比页上下滑动到底部，检查“小区类型”；NR 520830 显示“地铁专网”，原有高铁专网频点仍显示“高铁专网”。

## 基站标记与回读视角

地图“更多”菜单和绘图显示设置均提供“显示基站标记（三角标）”，偏好会保存。
该开关即时作用于已绘制及后续绘制的 LTE/NR 服务站和附近站标记，在正在路测与回读时
均有效。只修改标记可见性；采样、轨迹打点、基站快照记录、扇区和连线各自保持原有设置。
本来就不绘制基站标记的探测扇区图层不会被这个开关意外开启。

回读默认按照当前 SIM、当前频段筛选后的轨迹适配全览；只有一个位置时使用起点视角。
“更多 → 回读初始视角”可保存全览/起点偏好，并提供“轨迹全览”和“回到起点”的即时动作。
回读时切卡、修改频段筛选同样按所选偏好重新定位；视口未布局时延迟到地图加载完成，
不会被随后的首次 GPS 定位拉回用户当前所在地。
