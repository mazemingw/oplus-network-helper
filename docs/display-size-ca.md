# 显示大小与 QMI 主载波

本次仍为 1.6.0（60）。

- QMI NR-CA 频点降级信息现在先列出 PCC 主载波，再列出辅助载波。例如 N41 主载波与 N28、N79 辅载波会显示三项，主载波标记 PCC。主频点必须通过现有服务小区匹配检查；列表去重。只有主载波使用已有服务小区 PCI，不填造辅助载波 PCI、带宽或激活状态。工程模式优先级和 NRCA 不参与小区锁定的规则不变。
- 底部导航栏从屏幕宽度 86% 恢复全宽，只修改宽度，保留高度、圆角、模糊、颜色、图标和间距设计。
- 设置中的“字体大小”改为“显示大小”，提供 80%、90%、100%、110%、120%、130%。通过主题的 LocalDensity 同步缩放 Compose 控件、文字、间距和图标，移除旧的 Typography 额外字号缩放。默认 100% 跟随系统密度，同时保留系统字体及无障碍的非线性字体转换。
- 新设置使用独立 `display_size_level` 保存；不把旧 `font_size_level` 当作新密度比例，避免旧字号设置叠加或更新后意外改变整体大小。首次使用新设置默认 100%。松开滑块后生效，并保留重启后的选择。
- 此设置只调整应用的 Compose 界面，不修改手机系统密度；高德 SDK 与原生 View 控件仍使用系统密度。

主要修改：`QmiRadioSnapshot.kt`、`NetworkPanelContent.kt`、`NrCaDetailDialog.kt`、`AppRoot.kt`、`Theme.kt`、`DisplayDensity.kt`、`FontSizeConfig.kt`、`FontSizePreferences.kt`、`FontSettingsScreen.kt`、`SettingsScreen.kt` 及中英文资源。

验证：401 项单元测试，398 通过、3 项既有样本测试跳过、0 失败；Debug 构建成功。新增覆盖主辅载波顺序与去重、不虚构辅载波指标、系统密度下的 dp/sp 同比缩放、可用布局宽度、默认与错误值回退，以及系统非线性字体转换保留。构建日志：`build/display-ca-build.log`。

安装后可在“设置 → 显示大小”选择 80% 或 90% 检查拥挤设备，100% 恢复系统比例。确认底栏五项均可见、邻区频点列不再过窄、RX 面板和文字同时缩放，重启后仍保留选择。本轮尚未在截图中的设备上进行真机视觉验证。
